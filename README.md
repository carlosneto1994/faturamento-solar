# Faturamento Solar

Programa para gerar as faturas de energia solar a partir das contas da Energisa.

## Instalar

Baixe **Instalar-Faturamento-Solar.exe** na [versão mais recente](../../releases/latest) e dê dois cliques.
O atalho aparece na área de trabalho.

## Atualizações

O programa verifica este repositório ao abrir e a cada 6 horas (arquivo `versao.json`).
Quando há versão nova, ele baixa, confere o SHA-256 e se atualiza. Os dados ficam em
`Documentos\Faturamento Solar` e não são alterados.

Este repositório tem só o programa. Nenhum dado de clientes ou faturas é enviado para cá.
